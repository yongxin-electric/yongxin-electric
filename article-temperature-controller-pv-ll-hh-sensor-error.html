溫控器 PV 顯示 LL、HH 或感溫異常？先查感溫棒、配線與輸入設定

PV（目前溫度）出現 LL、HH、Sensor Error、s.err 或其他輸入異常代碼時，不一定就是溫控器本體故障。感測器、延長線、端子接線與 Input Type 都屬於同一條測溫訊號鏈，應依序核對。

發布日期：2026／08／12分類：溫控器、感溫棒、熱電偶、Pt100、故障排查
安全提醒

射出成型機、烤箱、乾燥機、熱封設備與工業電熱控制箱可能同時涉及高溫及市電。若 PV 顯示異常、溫度失控或加熱狀態不明，應先停止加熱並依設備程序斷電；量測或拆接端子應由具備電氣知識的人員執行，避免在通電狀態任意短接感溫輸入。

溫控器要能正確控制加熱，第一步就是收到正確的溫度訊號。當原本正常的 PV 突然跳成異常代碼、數值跑到極高或極低、加熱途中亂跳，或更換感溫棒後顯示完全不合理時，先不要只把焦點放在溫控器本體。不同品牌與型號對 LL、HH、Sensor Error、s.err 等代碼的定義不完全相同，實際代碼與判定條件仍應查閱該型號原廠手冊。

先把問題看成「整條測溫訊號鏈」

01

感溫元件

確認是 K、J 型熱電偶、Pt100 或其他 RTD／感測輸入，並檢查探棒本體是否損壞。

02

導線與端子

檢查斷線、鬆脫、氧化、延長線材、極性與端子位置，不要只看外觀是否「有接上」。

03

Input Type

核對溫控器完整型號及目前輸入設定，確認控制器實際設定與感測器種類一致。

04

控制器本體

前三項都核對後，再進一步判斷輸入電路、參數、顯示或控制器本身是否異常。

常見現象：不一定都是溫控器壞掉

  • 原本正常顯示溫度，突然變成 LL、HH、Sensor Error、s.err 或其他異常代碼。
  • PV 數值瞬間跑到極高或極低。
  • 設備加熱到一半，PV 開始不規則跳動。
  • 更換新的感溫棒後，數值反而完全不合理。
  • 控制器仍有顯示，但與現場實際溫度差距很大。

原因一：感測器、延長線或端子斷路

熱電偶的感測接點、延長／補償導線或端子若發生斷路，控制器可能判定為感測輸入異常。Pt100 的感測元件或其中一條導線斷路，也可能造成輸入錯誤或異常控制狀態。因此看到感溫異常時，應一起檢查探棒本體、導線連續性、端子鎖附與接點狀況，而不是只替換面板上的溫控器。

原因二：溫控器 Input Type 設定與感測器不一致

熱電偶

K 型、J 型等熱電偶會產生微小熱電勢，具有極性，控制器必須使用對應的熱電偶輸入曲線。

Pt100

Pt100 是白金測溫電阻，控制器依電阻變化換算溫度；常見工業接法包含 3 線式，輸入電路與熱電偶不同。

例如原本接 K 型熱電偶，控制器卻被設定成 Pt100；或原本是 Pt100，卻選成 J 型熱電偶，即使端子都有接線，顯示也可能明顯不合理，部分控制器甚至會直接判定輸入錯誤。更換溫控器或感溫棒後，務必核對完整型號、Input Type 參數與端子圖。

原因三：Pt100 三線式接法錯誤

工業用 Pt100 很常見 3 線式配置，目的之一是補償導線電阻造成的量測誤差。三條線並不是可以任意互換；應依所使用控制器的端子圖接線。許多控制器會以 A、B、B 表示 Pt100 三線端子，但實際標示仍以該型號手冊為準。

除了接錯端子之外，其中一條導線斷路，或三條延長導線的電阻條件差異過大，也可能造成顯示誤差或輸入異常。因此延長 Pt100 配線時，應使用低電阻且條件一致的導線，並避免只隨意補接其中一條線。

原因四：熱電偶正負極接反

熱電偶具有極性。若正負極接反，設備升溫時顯示可能朝相反方向變化，或出現明顯不合理的溫度趨勢；這種狀況在更換感溫線、接頭、端子或溫控器後特別容易發生。檢查時應依熱電偶種類、端子「＋／－」標示及原廠接線圖確認。

原因五：熱電偶延長線材使用錯誤

熱電偶訊號不應任意使用一般銅線延長。需要延長時，應使用與熱電偶種類相符的補償導線或延長導線，否則可能增加量測誤差。不同熱電偶種類所需的導線也不同，不能只因為線徑接近就互換。

原因六：高溫環境造成導線與絕緣材料劣化

感溫棒的感測端能承受某個溫度，不代表後方導線、外皮、接頭與端子也具有相同耐溫能力。PVC、矽膠、玻璃纖維、PFA 等配線材料的允許溫度與環境條件不同；長期靠近加熱管、模具或爐壁時，可能發生外皮硬化、熔化、脆裂或絕緣下降。

選擇感溫棒與配線時，不只要問「可以量到幾度」，還應一起確認感測端允許溫度、導線耐溫、保護管／護套條件、工作環境，以及是否需要額外的機械保護。各材料實際適用範圍應以該產品規格為準。

更換感溫棒時，建議至少核對這些資料

  • 感測器種類：K 型、J 型、Pt100 或其他熱電偶／RTD。
  • 接線方式：2 線、3 線或其他配置，並拍下原本接在哪些端子。
  • 探棒尺寸：直徑、插入長度與外型。
  • 安裝方式：有牙／無牙，若有螺牙需確認牙規與實際尺寸。
  • 線材：線長、外皮／耐熱需求、是否有金屬編織或其他保護。
  • 端末形式：叉型端子、接頭、接線盒或其他現場接線方式。
  • 使用條件：實際工作溫度、測量位置、介質與現場環境。
  • 溫控器資料：品牌、完整型號、背面端子圖及目前 Input Type 設定。

舊機台沒有完整型號時，照片怎麼拍最有用？

舊設備上的感溫棒常常已經沒有完整標籤，或外型與新產品不完全相同。這時候不要只帶一支「長得差不多」的感溫棒來比；建議同時拍下：

  • 溫控器正面品牌與完整型號。
  • 溫控器背面的接線圖、端子編號與實際接線。
  • 原感溫棒全貌、前端、螺牙與線材。
  • 探棒直徑、插入長度與安裝位置的尺寸參考。
  • 若可確認，提供設備正常工作時的大致溫度範圍。

先確認感測器、配線與設定，再決定更換哪個元件

PV 顯示異常，不一定就是溫控器本體故障。從感溫棒、補償／延長導線、端子、輸入設定到控制器本體，都是同一條測溫訊號鏈。永信電料行可依舊品型號、感測器種類、尺寸、牙規、線長及溫控器接線資料協助縮小規格範圍；如規格不清楚，也可攜帶舊品或樣品親臨門市核對。實際供應狀況、價格與交期請另行確認。
