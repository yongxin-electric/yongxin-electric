# 永信電料行網站

目前版本：v7.18.1

台中工業電料、自動控制元件與機台維修材料的 B2B 企業官網與商品型錄。

## 本版更新
- 新增每日一則技術專欄 #006：「溫控器 PV 顯示 LL、HH 或感溫異常？先查感溫棒、配線與輸入設定」。
- 文章以「感溫元件 → 導線／端子 → Input Type → 溫控器」的測溫訊號鏈為排查主軸，補充 Pt100 三線、熱電偶極性、補償導線與高溫配線核對。
- 技術內容依 OMRON 官方 Temperature Controller／Temperature Sensor 技術資料交叉核對；錯誤代碼與端子仍明確要求依實際品牌、型號手冊確認。
- `technical.html` 與首頁「最新技術文章」同步更新至每日一則 #006。

## 使用 GitHub Desktop 更新
1. 在 GitHub Desktop 選擇本專案，按 **Show in Explorer**。
2. 將新版 ZIP 解壓後的內容覆蓋至本機專案資料夾。
3. 回到 GitHub Desktop 檢查變更。
4. 輸入 Summary，按 **Commit to main**。
5. 按上方 **Push origin** 完成上傳。
