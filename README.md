# 永信電料行網站

目前版本：v7.16.0

台中工業電料、自動控制元件與機台維修材料的 B2B 企業官網與商品型錄。

## 本版更新
- 啟用商品總覽中的「溫控與量測」正式分類，新增 `category-temperature-measurement.html`。
- 新增 2 個客製溫度感測商品頁：客製感溫棒、客製大圓頭（接線頭型）溫度感測器。
- 每個客製品頁僅使用 1 張實際成品照片作為形式參考，並套用永信電料行浮水印；不公開訂製供應商／代工廠品牌。
- 新增客製規格確認表：感溫種類、探棒直徑／長度、螺牙、線長／接線、使用條件與需求數量等，未確認的固定規格不自行填寫。
- 加入客製品訂購提醒：規格確認並進入製作後，除規格不符、瑕疵或依法得主張之情形外，原則上不接受任意取消或退換；完成後請依約取貨／收貨。
- 商品搜尋索引由 177 增至 179 個商品頁，並同步修正 `products.html` 先前仍顯示 172 的舊計數。

## 使用 GitHub Desktop 更新
1. 在 GitHub Desktop 選擇本專案，按 **Show in Explorer**。
2. 將新版 ZIP 解壓後的內容覆蓋至本機專案資料夾。
3. 回到 GitHub Desktop 檢查變更。
4. 輸入 Summary，按 **Commit to main**。
5. 按上方 **Push origin** 完成上傳。

> 品牌 Logo 僅用於商品識別，不代表永信電料行為官方授權代理商；規格、庫存、價格與交期請另行確認。
