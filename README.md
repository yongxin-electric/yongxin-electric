# 永信電料行網站

目前版本：v7.18.0

台中工業電料、自動控制元件與機台維修材料的 B2B 企業官網與商品型錄。

## 本版更新
- 新增「PLC 與人機介面」主分類，第一批建立台達 DELTA DVP 系列 4 個商品頁。
- 新增 DVP12SA211T、DVP14SS211R、DVP60ES200T PLC 主機，以及 DVP16SP11R 16 點數位 I/O 擴充模組。
- PLC 商品頁採「實物銘牌＋台達官方 DVP 系列型錄／系列頁」交叉核對，完整列出 I/O、供電、輸出型式、程式容量、通訊與可確認的高速功能。
- 修正 DVP16SP11R 資料理解：模組 POWER INPUT 為 24VDC 2W；AC 負載電壓不可誤寫為模組供電。
- 台達電 DELTA 常見品牌卡改為可點擊品牌商品索引，首頁品牌 Logo 同步連至 `brand-delta.html`。
- 商品搜尋索引由 189 更新為 193 個商品頁。
- 正式新增「永信客製／特殊規格服務」集中入口，客製商品仍依實際用途保留在原功能分類，並新增至服務項目。

## 使用 GitHub Desktop 更新
1. 在 GitHub Desktop 選擇本專案，按 **Show in Explorer**。
2. 將新版 ZIP 解壓後的內容覆蓋至本機專案資料夾。
3. 回到 GitHub Desktop 檢查變更。
4. 輸入 Summary，按 **Commit to main**。
5. 按上方 **Push origin** 完成上傳。

> 品牌 Logo 僅用於商品識別，不代表永信電料行為官方授權代理商；規格、庫存、價格與交期請另行確認。
