# 永信電料行網站

目前版本：v7.6.0

台中工業電料、自動控制元件與機台維修材料的 B2B 企業官網與商品型錄。

## 本版更新
- 新增僑電企業 QDQ 品牌 Logo，顏色依使用者提供之保險絲包裝色系調整。
- 常見品牌頁與首頁品牌區新增僑電企業 QDQ。
- 海灣電氣 GULF Logo 更新為較大版本。
- 新增僑電 QDQ 保險絲與保險絲座分類頁。
- 新增 CT-10、E16 系列 15 個保險絲商品頁與 CT-FB101LA 保險絲座商品頁。
- 全部商品照片套用永信電料行浮水印，封面優先使用保險絲／保險絲座本體照片。

## 使用 GitHub Desktop 更新
1. 在 GitHub Desktop 選擇本專案，按 **Show in Explorer**。
2. 將新版 ZIP 解壓後的內容覆蓋至本機專案資料夾。
3. 回到 GitHub Desktop 檢查變更。
4. 輸入 Summary，按 **Commit to main**。
5. 按上方 **Push origin** 完成上傳。

小幅更新可只覆蓋 Patch 中的變動檔案，不必重新上傳全站。

> 品牌 Logo 僅用於商品識別，不代表永信電料行為官方授權代理商；規格、庫存、價格與交期請另行確認。
- 新增 KSS CV-250、CV-300、CV-300SB、CV-385、CV-200KB、CV-200M 尼龍束帶。
- KSS 束帶分類頁更新為 14 個型號，並修正 CV-100B 封面與商品照片 1／2 順序。
