# 永信電料行網站

目前版本：v7.17.0

台中工業電料、自動控制元件與機台維修材料的 B2B 企業官網與商品型錄。

## 本版更新
- 啟用商品總覽中的「開關與操作元件」正式分類，新增 `category-switches-operation.html`。
- 新增 NKK Switches 品牌／分類頁，依搖頭開關與翹板開關分組。
- 新增 10 個 NKK 商品頁：8 個 S／S300 搖頭開關、2 個 SW 翹板開關。
- 使用 34 張使用者提供的實拍商品照片，排除壓縮檔中的外部參考圖，全部重新套用永信電料行浮水印。
- 商品規格以本批實物銘牌為主要依據，並與 NKK 原廠資料交叉核對；不同年代／版本可能有額定標示差異時不互相推定。
- 商品搜尋索引由 179 增至 189 個商品頁；常見品牌與首頁 NKK Logo 改為可進入 NKK 商品索引。
- 將客製品「可來電或攜帶舊品／樣品親臨門市核對」等洽詢原則正式寫入 `PROJECT_RULES.md`。

## 使用 GitHub Desktop 更新
1. 在 GitHub Desktop 選擇本專案，按 **Show in Explorer**。
2. 將新版 ZIP 解壓後的內容覆蓋至本機專案資料夾。
3. 回到 GitHub Desktop 檢查變更。
4. 輸入 Summary，按 **Commit to main**。
5. 按上方 **Push origin** 完成上傳。

> 品牌 Logo 僅用於商品識別，不代表永信電料行為官方授權代理商；規格、庫存、價格與交期請另行確認。
