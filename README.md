# 永信電料行網站

目前版本：v7.20.1

台中工業電料、自動控制元件與機台維修材料的 B2B 企業官網與商品型錄。

## 本版更新
- v7.20.1 強化 `category-automation.html` 的繼電器品牌可見度：新增 IDEC／OMRON 品牌快速入口卡與側欄直達連結，同時保留「繼電器與控制繼電器」總分類。
- v7.20.0 新增 IDEC 和泉電氣 RR／RU 繼電器與 SJ 繼電器插座 6 個商品頁；搜尋索引更新至 199 頁。
- v7.19.1 將 193 個商品頁對客戶顯示的「規格補充與原廠核對」統一簡化為「詳細規格」；資料來源層級與內部核對邏輯維持不變。
- v7.19.0 為「全站商品規格完整化」第一階段，以 v7.18.1 為可回退基準。
- 193 個既有商品頁全部新增「詳細規格」區塊；完整型號可確認者補入原廠主要規格，舊型號或僅能確認系列資料者明確標示資料層級。
- 商品搜尋索引同步收錄既有規格表與新增核對資料，可用電壓、電流、接點、I/O、輸出型式、尺寸／安裝等關鍵字輔助查找。
- 本階段不建立未驗證的跨品牌替代關係；無法由完整型號原廠資料或實物銘牌確認的欄位維持不推定。

## 使用 GitHub Desktop 更新
1. 在 GitHub Desktop 選擇本專案，按 **Show in Explorer**。
2. 將新版 ZIP 解壓後的內容覆蓋至本機專案資料夾。
3. 回到 GitHub Desktop 檢查變更。
4. 輸入 Summary，按 **Commit to main**。
5. 按上方 **Push origin** 完成上傳。

> 品牌 Logo 僅用於商品識別，不代表永信電料行為官方授權代理商；規格、庫存、價格與交期請另行確認。


## v7.19.0 規格完整化（第一階段）
- 全站 193 個既有商品頁新增「詳細規格」區塊。
- 規格來源區分實物銘牌、完整型號原廠資料與系列共通資料；不得以同系列推定未確認尾碼。
- 商品搜尋索引納入商品頁規格欄位，支援品牌／型號以外的規格關鍵字搜尋。
- 下一階段可在此資料基礎上建立跨品牌替代型號比對。
