# 永信電料行網站

目前版本：v7.15.0

台中工業電料、自動控制元件與機台維修材料的 B2B 企業官網與商品型錄。

## 本版更新
- 新增「自動控制元件 → 計數器與長度計數器」正式分類，採品牌分層架構，方便後續加入其他品牌與型號。
- 新增 LINE SEIKI 品牌商品索引、計數器分類頁與 5 個商品詳細頁。
- 新增商品：MCF-6X AC 110V、MCF-6X AC 220V、MCF-6XUL DC 24V、MWC 3:1-5(I)、RY1-3:10-5(I) YP。
- 原始 22 張照片比對後有 2 組跨電壓型號的完全相同共用照片；為避免不同電壓商品頁重複造成混淆，實際採用 18 張不重複照片並套用永信電料行浮水印。
- RY1 商品完整型號依本體銘牌採用 `RY1-3:10-5(I) YP`，未將資料夾中未能由本體確認的額外字樣直接寫入規格。
- 常見品牌頁與首頁 LINE SEIKI Logo 改為可直接進入品牌商品索引。
- 自動控制元件已建立數量由 85 更新為 90 個型號／規格，並重新產生全站商品搜尋索引。
- 專案交付規則新增：每次網站修改更新包的回覆固定附上「建議 Commit Summary」。

## 網站
GitHub Pages：`https://yongxin-electric.github.io/yongxin-electric/`

## 使用 GitHub Desktop 更新
1. 在 GitHub Desktop 選擇本專案，按 **Show in Explorer**。
2. 將新版 ZIP 解壓後的內容覆蓋至本機專案資料夾。
3. 回到 GitHub Desktop 檢查變更。
4. 輸入 Summary，按 **Commit to main**。
5. 按上方 **Push origin** 完成上傳。

> 品牌 Logo 僅用於商品識別，不代表永信電料行為官方授權代理商；規格、庫存、價格與交期請另行確認。
