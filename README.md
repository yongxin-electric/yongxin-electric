# 永信電料行網站

目前版本：v7.13.0

台中工業電料、自動控制元件與機台維修材料的 B2B 企業官網與商品型錄。

## 本版更新
- `products.html` 新增全站商品關鍵字搜尋，可依品牌、完整型號、系列、電壓、電流與商品類型即時查找。
- 建立 `assets/product-search-index.js`，目前索引 172 個商品詳細頁。
- 搜尋支援空格與常見型號分隔符差異，例如 `BH3P32A`、`BH 3P 32A`、`OMRON DC24V`。
- 搜尋結果直接顯示商品照片、品牌、型號、產品類型與主要已確認規格，點擊即可進入商品詳細頁。
- 商品總覽的自動控制元件已建立數量同步修正為 85 個型號／規格。

## 網站

## 使用 GitHub Desktop 更新
1. 在 GitHub Desktop 選擇本專案，按 **Show in Explorer**。
2. 將新版 ZIP 解壓後的內容覆蓋至本機專案資料夾。
3. 回到 GitHub Desktop 檢查變更。
4. 輸入 Summary，按 **Commit to main**。
5. 按上方 **Push origin** 完成上傳。

> 品牌 Logo 僅用於商品識別，不代表永信電料行為官方授權代理商；規格、庫存、價格與交期請另行確認。
